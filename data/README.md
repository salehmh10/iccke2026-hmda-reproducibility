# Data policy

Only aggregate evidence, schemas, and artifact manifests are included. Raw and processed applicant rows, membership identifiers and row hashes, predictions, individual sensitive values, and model objects are intentionally excluded.

Start with [data provenance](../docs/DATA_PROVENANCE.md) and [sampling design](../docs/SAMPLING_DESIGN.md). Exact experiments cannot be rerun from this repository alone. The package supports evidence inspection and synthetic validation; access, licensing, complete environments, and source-data authorization must be resolved separately.
