# Data policy

Only aggregate evidence, schemas, and artifact manifests are included. Raw and processed applicant rows, membership identifiers and row hashes, predictions, individual sensitive values, and model objects are intentionally excluded.

Start with [data provenance](../docs/DATA.md) and [sampling design](../docs/DATA.md). Exact experiments cannot be rerun from this repository alone. This update supports static evidence inspection only; access, licensing, complete environments, and source-data authorization must be resolved separately.
