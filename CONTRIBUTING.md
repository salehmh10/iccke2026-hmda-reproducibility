# Contributing

Read AGENTS.md first. Changes must preserve evidence generation, target orientation, and source lineage. Propose documentation or validator fixes through a branch and Pull Request. Never add data rows, membership, predictions, models, credentials, or manuscript edits. For this saved-results publication, use static inspection only. Do not rerun notebooks, research workflows, tests, validators, builds, or CI unless explicitly authorized by the authors. Preserve all published scientific artifacts and update publication metadata only when needed. Publication-file checksums may be refreshed through static file operations without running project validators. Scientific recomputation requires a separate explicitly approved protocol. Contributions accepted into this repository will be distributed under the MIT License unless otherwise stated. Contributors must not add data, third-party code, or other materials that they do not have permission to distribute.
